# First real Compatibility Pack template and acceptance

Status: Future acceptance entry; no real third-party Mod pack is claimed by this document.

Start from a copied, renamed manifest based on the declaration-only `.mcac-compat/1` schema already
covered by `CompatibilityPackLoaderTest`. The first field pack must identify one exact Mod version,
Minecraft version and Loader fingerprint; declare only Registry-visible capabilities actually
observed on a connected body; and contain no Java, script, native library, credentials or host path.

Required evidence:

1. Capture the Mod artifact hash and sanitized Registry/recipe/tag/menu observations.
2. Install into an isolated Compatibility Store, run the declared Fixture/GameTest externally, and
   let the trusted test runner record evidence before index/activation through the scoped Host flow.
   A local Terminal user must not submit `passed=true` or choose `EXACT_VERIFIED`.
3. Show the Compatibility UI source pack, hash, state, risk and any suppression reason.
4. Execute one bounded generic task through existing primitive Tools and verify the final world or
   inventory observation. Unsupported special mechanics must return a stable unsupported result.
5. Exercise stale fingerprint suppression, disable, update, rollback, quarantine and restart
   recovery. Run `:compatibility:compatibility-host:test` and the relevant real Loader GameTest.
6. Record the evidence class precisely. A Fixture proves the Host, not Create, AE2, Mekanism or
   arbitrary-Mod compatibility.

The manifest template below uses the real strict Loader schema. It is intentionally non-installable
until every placeholder is replaced, the required capability/evidence documents and
`SHA256SUMS.txt` are added, and the archive hash/evidence are generated by the acceptance run:

```yaml
schemaVersion: mcac-compat/1
pack:
  id: replace_with_mod_namespace_and_feature
  version: 0.1.0
  type: MOD
  displayName: Replace with reviewed pack name
  authorType: external-agent
  createdAt: 2026-01-01T00:00:00Z
target:
  minecraft:
    exact: replace_exact_minecraft_version
  loader:
    type: replace_exact_loader
    versionRange: replace_exact_loader_version
  mods:
    - id: replace_mod_id
      versionRange: replace_exact_mod_version
      jarHash: replace_with_sha256
runtime:
  minimumHostVersion: 1
  nativeCode: false
  hotReloadable: true
  restartRequired: false
permissions:
  declared:
    - REGISTRY_READ
    - WORLD_OBSERVE
  forbidden:
    - SHELL
    - ARBITRARY_FILE_ACCESS
    - DIRECT_WORLD_EDIT
    - CREDENTIAL_READ
    - PROCESS_EXEC
    - NETWORK_UNBOUNDED
dependencies: []
conflicts: []
replaces: []
extends: []
patches: []
precedence: 0
limitations:
  - replace_with_verified_limitation
```

Capabilities are separate bounded documents such as `capabilities/tools.json`; they are not legal
manifest fields. This template is a follow-up entry, not a universal pack and not release evidence.
